Despliegue en Netlify con DecapCMS

(Agosto 2026)

Si vas a desplegar en Netlify, lo más rápido y cómodo es GitHub, GitLab o Bitbucket, porque Netlify se conecta automáticamente a ellos para compilar la web cada vez que publicas algo en el CMS.

Decap CMS (anteriormente Netlify CMS) funciona guardando los cambios como commits directos en un repositorio. Para eso tiene tres opciones principales:

  1. GitHub
  2. Otros proveedores de Git: GitLab: (que soporta Auth directo y Git Gateway), Bitbucket o Gitea / Codeberg: (si tienes un servidor Git propio e independiente).
  3. Con un Backend Personalizado / Base de datos: Decap permite conectar backends de terceros (como GraphQL o bases de datos propias), pero requiere programar un servidor intermedio a medida, lo cual suele quitarle la gracia a la simplicidad de Astro + Markdown.

Pasos para deplegar el proyecto en Github

Antes de proceder con los pasos hay que revisar el archivo /public/config.yml para asegurarse de que el contenido del mismo esté correcto

1. Crea el repositorio en GitHub

  1. Inicia sesión en https://github.com/.
  2. Crea un nuevo repositorio clicando sobre Repositories y luego sobre el botón New
  3. Dale un nombre
  4. Elige si prefieres que sea Público o Privado.
  5. Deja desmarcadas todas las casillas (Add a README file, Add .gitignore, Choose a license). El repositorio debe crearse totalmente vacío.
  6. Haz Haz en Create repository.

2. Sube los archivos a GitHub

  1. En la pantalla que aparece justo después de crear el repositorio, verás un enlace en el recuadro azul de Quick Setup que dice: uploading an existing file (subir un archivo existente). Haz clic ahí.
  2. Abre la carpeta de tu proyecto en tu ordenador.

  3. Selecciona y arrastra TODOS los archivos y carpetas pertinentes hacia la ventana del navegador.

    Es IMPORTANTE que NO arrastres las carpetas node_modules, dist, ni .astro.

    Las carpetas a subir son src/, public/, y los archivos de configuración del proyecto: package.json, pnpm-lock.yaml, astro.config.mjs, etc. (leer detenidamente el presente tutorial).

  4. Espera a que se terminen de procesar todos los archivos.
  5. Haz clic en el botón verde Commit changes.

3. Conecta GitHub con Netlify

  1. Inicia sesión en https://app.netlify.com/.
  2. Clica sobre el botón Add new project.
  3. Selecciona la opción Github bajo la opción Import a Git repository: (se abrirá una ventana emergente para vincular tu cuenta de GitHub con Netlify).
  4. Configura los campos de Build settings exactamente con estos valores:
    • Branch to deploy: main (déjalo como está)
    • Base directory: (déjalo en blanco)
    • Build command: pnpm run build
    • Publish directory: dist
    • Functions directory: (déjalo en blanco)
  5. Una vez rellenados esos campos, haz clic en el botón Deploy [nombre-de-tu-proyecto] que aparece abajo del todo. Netlify comenzará a compilar tu web y en cuestión de 1 o 2 minutos te dará la URL pública.

4. Incluye el script de Netlify Identity Widget

DecapCMS necesita el script del widget de Netlify Identity en la página del panel para capturar el token de sesión. Abre el archivo HTML de tu panel de administración de DecapCMS (/public/admin/index.html) y asegúrate de que contenga el script en el <head>:

5. Activa DecapCMS en Netlify

Selecciona tu proyecto (blog)

a. Activar Identidad

  1. Selecciona Identity en el Panel|Menú lateral
  2. Haz clic en Enable Identity.

b. Activar Git Gateway

  1. En la misma página de Identity, baja hasta el apartado Services
  2. Busca Git Gateway y haz clic en Enable Git Gateway (esto dará permisos a Netlify para escribir en el repositorio de GitHub cuando se guarden cambios desde el CMS).

c. Crear la cuenta de acceso

  1. Selecciona Identity en el Panel|Menú lateral.
  2. Haz clic en Invite users e introduce tu correo electrónico.
  3. Recibirás un correo de confirmación: abre el enlace, asigna tu contraseña y listo.

d. Accede directamente al CMS

  1. Entra a https://[tu-blog].netlify.app/admin/
  2. Haz clic en Login with Netlify Identity (o el botón de Netlify).
  3. En la ventana emergente que se abre, selecciona la opción Continue with Google (o entra con el botón de Google).
