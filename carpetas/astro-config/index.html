¿Qué es el archivo astro.config.mjs?

Es el archivo principal de configuración de Astro. Es el "cerebro" donde le indicas al framework cómo debe comportarse, qué herramientas adicionales va a usar y cómo va a construir el sitio web.

¿Qué se configura dentro de astro.config.mjs

  1. Integraciones (Integrations):Aquí es donde registras frameworks UI o librerías externas que uses con Astro (como React, Vue, Tailwind CSS, Svelte, MDX, Sitemap, etc.).

  2. Adaptadores de despliegue (Adapters):Si el sitio requiere renderizado en el servidor (*Server-Side Rendering / SSR*), aquí se configura el adaptador específico para el hosting (como @astrojs/vercel, @astrojs/netlify o @astrojs/cloudflare).

  3. URL del sitio web:En esta sección se define el dominio final del proyecto (ejemplo: 

    site: https://miweb.com
    ). Astro usa esta URL para generar automáticamente mapas del sitio (sitemap.xml), feeds RSS y URLs absolutas para SEO.

  4. Redirecciones y Rutas:Puedes definir reglas de redirección permanente o temporal de URLs antiguas a nuevas.

  5. Opciones del Servidor y Vite:Astro utiliza Vite por debajo para compilar el proyecto. Desde este archivo puedes personalizar opciones del servidor de desarrollo (como el puerto) o plugins avanzados de Vite.

¿Dónde se ubica?

En la raíz del proyecto (al mismo nivel que package.json).

¿Se sube a Git y al Hosting?

A Git / GitHub: SÍ.

Es un archivo vital del código fuente. Todo tu equipo necesita la misma configuración.

Al Hosting: SÍ

Vercel/Netlify/Cloudflare lo necesitan en el repositorio de GitHub para saber cómo compilar el sitio correctamente con npm run build.
